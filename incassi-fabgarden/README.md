# Fab Garden — Incassi

Web app installabile per registrare gli incassi di Fab Garden.

- I dati restano sul dispositivo tramite `localStorage`.
- I pulsanti Export/Import permettono di creare e ripristinare un backup JSON.
- Il service worker consente l'apertura offline dopo la prima visita.
- Il manifest e l'Apple touch icon permettono l'installazione sulla Home dell'iPhone.

## Installazione su iPhone

Aprire il sito pubblicato con Safari, scegliere **Condividi**, quindi **Aggiungi alla schermata Home** e attivare **Apri come app**.
